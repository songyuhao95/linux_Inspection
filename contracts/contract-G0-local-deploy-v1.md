# G0 本地部署与验证补充合同 v1

本补充合同只授权 `node01`（`192.168.0.10`）和 `kylin01`（`192.168.0.101`）。它不修改或放宽 `contract-G0-real-vm-v1` 的远程只读边界；本合同单独授权把当前脚本写入两台 VM 的 `/data/inspect`，并在 Ansible 不存在时从目标机已经配置的原生软件源安装 `ansible-core`。

部署和安装必须逐台执行。安装前只做定向版本、包管理器和仓库检查；不得添加第三方仓库，不得使用 `pip`、下载脚本或 `curl | bash`。缺少 root/sudo 权限、原生仓库、可用 SSH key/TTY 或安全凭据通道时停止。

巡检执行必须使用：

```text
INSPECT_ENABLE_REAL=1
INSPECT_ENABLE_LOCAL_REAL=1
```

并从 `/data/inspect` 使用生成的 `localhost ansible_connection=local` inventory 运行。不得设置远程账号、`INSPECT_ASK_PASS`、密码环境变量或密码文件。命令仍限于既有只读 allow-list，`gather_facts=false`、`serial=1`、`raw`、`/bin/bash -lc`、无重试和结构化 JSON callback 约束继续有效。

验证证据只能记录 VM 标签、授权 IP、执行时间、源文件/清单哈希、Python/Ansible 版本、退出码、执行状态计数、指标状态计数、耗时和脱敏错误类别。密码、密钥、原始 callback、原始 SSH 诊断、命令输出和未脱敏日志不得写入报告、Git、事件记录或聊天。

本合同不授权 commit、push、业务数据修改、服务停止、配置修改或任何未列明目标。
