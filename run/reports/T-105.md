## 7. 设计决策（D）

- **D1（原因分类，RR §2 四类显式）**：error.code 直映射 permission/timeout/missing（PERMISSION_DENIED/TIMEOUT/COMMAND_NOT_FOUND/DATA_MISSING）；未映射错误码显式 `other:<code>` 绝不静默（PARSE_FAILED/UNSUPPORTED_PROFILE/CONNECTION_FAILED 等原样展示）；业务 UNKNOWN（无 error）按 threshold/provenance 注记关键词（冲突/缺失及 C3/C8/C10/C4/C5/C13 编号，与 config 基线 UNKNOWN reason 语义一致），layer=None（无判定依据）→ missing。
- **D2（计数不二次计算）**：全部状态计数取 JSON `execution_summary` 逐文档聚合（RR §6.1 三类报表计数一致），渲染层不重算判定。
- **D3（执行徽标与业务徽标区分）**：execution_status 徽标加粗+色，业务徽标不加粗（RR §5）；无颜色环境两者均为文本缩写，靠 [SUCCESS]/[PARTIAL]/[ERROR] 与 [OK]/[WARN]/[CRIT]/[UNKN] 文本区分。
- **D4（ERROR 主机渲染）**：AE §6 无业务结论——输出"无业务结论（executed=0 failed=3）"；主机级错误明细（code/message）取自汇总索引 `hosts[].error`（T-104 报告 D1 同源，schema 无主机级 error 字段），失败列表另注"主机级执行失败：无业务指标"。
- **D5（色板与检测）**：RR §5 四状态色板语义以标准 ANSI 前景色近似（绿/黄/红/灰），HTML 报表（后续任务）用精确 hex；NO_COLOR/TERM=dumb/stream 非 TTY 均禁色（no-color.org 约定），`color=`/`force=` 显式参数优先供测试与调用方决定。
- **D6（零采集架构）**：渲染模块导入面仅 fact_source 读路径；测试以 mock 断言 ansible_runner.run / subprocess.run 零调用 + 源码 import 机械扫描双保险。
- **D7（空态显式）**：无主机文档、无 UNKNOWN/ERROR 均输出显式占位文本，RR §6.2 不得静默消失。
- **D8（输入物化）**：主检出中全部规范/契约/已集成模块为未提交文件（baee20b 仅骨架）→ 按 T-103/T-104 先例字节级物化进工作树并 sha256 核对（§6 全部匹配）。
