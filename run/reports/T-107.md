## 4. 安全审查（不可信文本转义 + 内嵌 JSON 防越界）

- **HTML 转义（合同 mitigation，测试断言 `<script>` 注入被转义）**：所有不可信文本（evidence 命令/日志片段、error.message、threshold source_anchor、provenance 备注、主机名、IP）经 `esc()` = `html.escape(quote=True)`（`& < > " '` 全转义，正文与属性双安全）。`test_script_injection_escaped_everywhere` 将 `<script>alert(1)</script>` 注入 evidence/error.message/provenance 三处 → 正文 `&lt;script&gt;alert(1)&lt;/script&gt;`（≥3 处），原始载荷不出现；`test_attribute_injection_escaped` 用 `x" onclick="alert(1)` 主机名验证属性级注入被 `&quot;` 中和。
- **内嵌 JSON 防 `</script>` 越界**：`_embed_json` 将 `</` 转义为 `<\/`（合法 JSON 转义，浏览器解析后原样恢复）；`test_script_tag_breakout_escaped` 注入 `</script><script>alert(1)</script>` → 内嵌块内无原始 `</script>`，`json.loads` 往返与事实源一致，载荷留在数据块内（REQ-R-05 安全项）。
- **`$` 原样保留（string.Template 值语义）**：映射值原样插入、不参与模板语法解析，因此数据内 `$HOME`/`cost $10.5` 原样输出、无 `$$` 篡改（`test_embedded_json_keeps_dollar_signs`/`test_dollar_in_body_preserved`）；模板正文仅含 10 个合法占位符，渲染产物零残留（`test_no_placeholder_leftover`，含 `$` 的 JS 注释改写为"美元符号"表述规避误解析）。
