- **三 Sheet 布局（RR §3 表格）**：
  - Overview：run 信息（run_id/inspection_id/host/collected_at/duration_sec/execution_status）、主机×状态汇总（逐主机 OK/WARN/CRIT/UNKNOWN + execution_status 徽标 + executed/failed）、状态计数（合计，UNKNOWN 独立列 + 总计）、阈值版本（rule_id 前缀，如 linux-common-p0-v1）、生成时间；

- **四状态文字+背景色（RR §5）**：模块级常量 `STATUS_COLORS` = OK #2E7D32 / WARN #F9A825 / CRIT #C62828 / UNKNOWN #757575（测试断言常量值）；status 单元格白字 + 状态色背景；**CRIT 值红色字体**（用户需求：达到告警阈值的 raw_value/normalized_value 单元格 font_color=#C62828）；execution_status 以深色字浅灰底徽标区分于业务四状态（RR §5）。
